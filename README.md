# Power Flow Services Ltd - Website & Admin Portal

## 🚀 Quick Start

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the application:**
   ```bash
   npm start
   ```

3. **Access the application:**
   - **Client Website**: http://localhost:3000
   - **Admin Portal**: http://localhost:3000/admin

## 🛠️ Available Commands

- `npm start` - Run the website (client + admin)
- `npm run backend` - Run backend API separately
- `npm run dev` - Run with auto-reload (development)
